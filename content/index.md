Note taking conventions:
- **Polish**: Notes that are ready but need some clean up/polish identify as such by referencing the note [[Polish]]
- **Dump**: Clean/Ready notes may have an accompanying messy note for accumulating thoughts, it's a buffer/inbox/staging area for content that may later be transferred to the clean version of the note. such notes are named by appending "(Dump)" to the basename
* **Merge**: I often write about the same stuff on various notes. when i discover such notes, i reference the note [[Merge]] in a sentence explaining what notes to merge into. later on, i can just visit the [[Merge]] note to see all the notes linking back to it.
