- Project Gutenberg distributes digitized eBooks and other cultural works, visit at <https://www.gutenberg.org>
- Archive.org is a digital library offering free access to books, movies, music, software, and archived web pages, visit at <https://archive.org>
- Openlibrary is a project by Archive.org. it allows downloading and accessing public domain books. it also allows access to copyrighted books through "Controlled Digital Lending", visit at <https://openlibrary.org/>
- Librivox offers public domain audiobooks read by volunteers, visit at <https://librivox.org/>
- Hathitrust allows viewing and downloading public domain books, visit at https://babel.hathitrust.org/
- Doabooks allows access to scholarly, academic peer-reviewed open access books, visit at https://www.doabooks.org/

see [[Shadow Library|shadow libraries]] for copyrighted works.
