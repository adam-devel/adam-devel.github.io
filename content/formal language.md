title: Formal Languages
---

A formal language $L$ is a set of strings.
A string (or word) is a finite sequence of symbols.
A symbol (or letter) is any element in some alphabet.
An alphabet $\Sigma$ is any set.

More concisely: any set of finite sequences is a formal language.

# Conventions

- Language: $L$
- Word: $w, x, y, ..$
- Letter: $a, b, c, ...$
- Alphabet: $\Sigma$

# In other formalisms

Because of the broad scope of the definition, many formalism produce objects that qualify as formal languages. the following are some examples.

- the set of strings generated by a formal grammar
- the set of strings matched by a regular expression
- the set of strings accepted by a finite state machine (or any other atomata)
- the set of strings parsed successfully by an algorithm
