# Prerequisites

**The internet and the web**

- The internet is the physical networks and technologies that connect the computers of the entire world together
- The web is a technology that runs websites: HTML, CSS, JS, etc..

**The web**

The main technologies of the web (the technologies that run websites) are mainly HTML, CSS, JavaScript and HTTP
- HTML lists the elements in the website: buttons, inputs, paragraphs, etc..
- CSS describe the style of the elements in the page
- JS programs websites and manipulates the style and the content of the HTML elements
- HTTP describes how to send and recieve HTML, CSS, JavaScript and other data.

The browser reads these language and draws the website.

**Clients and servers**

The browser runs HTML, CSS and JS that make up the website. but where do we get the website from ? well you get it from a server: every website is stored in a server, including wikipedia and google and so on.

![](client-server.png)
 **Why PHP ?**
 
 The purpose of PHP is to let the server send different html for different users. for example: to display a different profile picture and name for each logged‑in user, the server must send different HTML for each user instead of just sending a html file directly without changes.
 
 PHP runs code on the server to decide what html to generate for every different user. This dynamic generation is why PHP (and similar server‑side languages) is needed.
